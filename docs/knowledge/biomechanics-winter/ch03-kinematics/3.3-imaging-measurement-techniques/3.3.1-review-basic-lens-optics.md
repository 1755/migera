# 3.3.1 Review of basic lens optics

> **Source:** Winter (2009) §3.3.1, p. 54 ·
> [open PDF at p. 54](../../../../books/bmcoh/BIOMECHANICS_AND_MOTOR_CONTROL_OF_HUMAN.pdf#page=67) ·
> Up: [3.3 Imaging measurement techniques](./INDEX.md)

Every imaging system has a lens. For a subject far from the camera the image
forms at the focal length, so object size maps to image size by similar
triangles, and the largest possible image (via a zoom lens) gives the best
accuracy.

## Key ideas

- A converging lens forms an inverted image at distance v when the object is
  at distance u (Fig. 3.8).
- In movement studies u ≫ v, so $1/u \approx 0$ and the image lies at the
  focal length.
- Image size relates to object size by triangulation through f; to keep the
  same image size as the subject distance L grows, f must grow in proportion
  (Fig. 3.9). A zoom lens varies f continuously, which is why it is preferred
  over a set of fixed lenses: accuracy is best when the image is as large as
  possible.

## Equations and numbers

$$\frac{1}{f} = \frac{1}{v} + \frac{1}{u} \quad (3.1) \qquad
u \gg v \Rightarrow \frac{1}{u}\approx 0,\ \frac{1}{f} = \frac{1}{v},\ f = v \quad (3.2)$$

Typical focal lengths: normal 25 mm, wide-angle 13 mm, telephoto 150 mm.
