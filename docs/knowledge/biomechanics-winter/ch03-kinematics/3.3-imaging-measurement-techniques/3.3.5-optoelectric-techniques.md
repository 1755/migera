# 3.3.5 Optoelectric techniques

> **Source:** Winter (2009) §3.3.5, pp. 61–63 ·
> [open PDF at p. 61](../../../../books/bmcoh/BIOMECHANICS_AND_MOTOR_CONTROL_OF_HUMAN.pdf#page=74) ·
> Up: [3.3 Imaging measurement techniques](./INDEX.md)

Active systems put a small infrared LED (IRED) on each landmark and flash
them one at a time, so every flash is automatically identified. OPTOTRAK
locates each flash in 3D from three linear sensor arrays, giving far better
precision than scan-line-limited video, at the cost of wired markers.

## Key ideas

- **Watsmart** (Northern Digital, Waterloo): first commercial active system;
  sequential IRED flashes focused onto a semiconductor diode surface.
- **OPTOTRAK geometry** (Figs. 3.14–3.15): three lenses on a rigid bar. The
  two outer lenses face slightly inward with horizontal linear diode arrays;
  each places a flash in a vertical plane, and the two planes intersect in a
  vertical line. The middle lens, with a vertical array, places the flash in
  a horizontal plane. Line ∩ plane = one 3D point in the global reference
  system.
- **Advantages:** no software needed to identify markers (each pulses at its
  own time), so marker sets can change day to day; precision is not limited
  by scan-line spacing.
- **Precision:** 0.03 mm, noise 0.015 mm, camera 4 m from the subject
  (Gage et al., 2004).
- **Disadvantages:** limited number of IREDs; cables to power the active
  markers encumber the subject.
