# 8.6 Illustrative example

> **Source:** Winter (2009) §8.6, pp. 217–222 ·
> [open PDF at p. 217](../../../books/bmcoh/BIOMECHANICS_AND_MOTOR_CONTROL_OF_HUMAN.pdf#page=230) ·
> Up: [Chapter 8 — Synthesis of human movement, forward solutions](./INDEX.md)

Contents: [model](#model) · [lists](#lists-and-kinematics) · [Lagrangian](#lagrangian) · [equations of motion](#equations-of-motion-corrected) · [typos](#printed-typos) · [lesson](#the-coupling-lesson)

Standing balance is modelled as a 3-segment inverted pendulum (leg, thigh,
HAT) on an ankle that can slide horizontally. Working through the list
recipe gives four equations of motion. Winter calls them "highly nonlinear,
tightly coupled, lengthy, and prone to errors". The printed versions prove
the point, since four of the five main expressions contain typos. The
lesson is coupling: the HAT mass $m_3$ appears in every equation, so an
error in any one segment parameter corrupts every coordinate and
accumulates over time. **There are no numerical results.** The example
ends at the symbolic equations.

## Model

- Segments: 1 = leg, 2 = thigh, 3 = trunk/HAT (Fig. 8.5a). Lengths $l_i$.
  COM distances $r_i$ are measured from each segment's **distal** end.
- Inputs: ankle, knee and hip torques $T_1, T_2, T_3$; a horizontal
  disturbance force $F$ at the hip; and a horizontal ankle perturbation
  (a prescribed acceleration $\ddot x$ of the ground contact point).
- Generalized coordinates: $q_1 = x$ (ankle horizontal position), and
  $q_2, q_3, q_4$ = **segment** angles of leg, thigh and HAT, measured from
  the global $+X$ axis (upright ≈ 90°). The text calls them
  $\theta_1..\theta_3$ in one place and "$(\theta_2,\theta_3,\theta_4)$"
  in another. The book deliberately uses segment angles, not joint angles,
  puts each LRS origin at the segment's distal end, and does not solve for
  joint reactions (shared-point joints, §8.5).

## Lists and kinematics

```
LRS(1) = [1, q2]   LRS(2) = [3, q3]   LRS(3) = [5, q4]
pt(1) = [0, q1, 0]  pt(2) = [1, r1, 0]  pt(3) = [1, l1, 0]
pt(4) = [2, r2, 0]  pt(5) = [2, l2, 0]  pt(6) = [3, r3, 0]
seg(1) = [2, m1, I1]  seg(2) = [4, m2, I2]  seg(3) = [6, m3, I3]
trq(1) = [0, 1, T1]  trq(2) = [1, 2, T2]  trq(3) = [2, 3, T3]
frc(1) = [5, F, 0]                      # hip = pt(5)
```

Pseudo-code: for each point, derive disp/velo (8.16, 8.17). For each seg,
add KE and PE to $L$ (8.5, 8.23, 8.25). For each torque and force, add its
work to $W$ (8.34). For each $q_i$, apply Lagrange's equations (8.8, 8.9).

COM positions (as printed, correct):
$\mathrm{disp}(2) = [q_1 + r_1c_2,\ r_1s_2]$,
$\mathrm{disp}(4) = [q_1 + l_1c_2 + r_2c_3,\ l_1s_2 + r_2s_3]$,
$\mathrm{disp}(6) = [q_1 + l_1c_2 + l_2c_3 + r_3c_4,\ l_1s_2 + l_2s_3 + r_3s_4]$.
Here $c_k = \cos q_k$ and $s_k = \sin q_k$. The velocities are their time
derivatives. The printed velo(4) has $r_1$ where $r_2$ belongs.

## Lagrangian

Define the grouped constants

$$M = m_1+m_2+m_3,\quad A = m_1r_1 + (m_2+m_3)l_1,\quad B = m_2r_2 + m_3l_2,\quad C = m_3r_3$$
$$J_1 = m_1r_1^2 + I_1 + (m_2+m_3)l_1^2,\quad J_2 = m_2r_2^2 + I_2 + m_3l_2^2,\quad J_3 = m_3r_3^2 + I_3$$

The collected Lagrangian (the book's simplified form, corrected) is:

$$\begin{aligned}L ={}& \tfrac12 M\dot q_1^2 + \tfrac12 J_1\dot q_2^2 + \tfrac12 J_2\dot q_3^2 + \tfrac12 J_3\dot q_4^2\\ &- \dot q_1\dot q_2\,A s_2 - \dot q_1\dot q_3\,B s_3 - \dot q_1\dot q_4\,C s_4\\ &+ \dot q_2\dot q_3\,l_1B\cos(q_3-q_2) + \dot q_2\dot q_4\,l_1C\cos(q_4-q_2) + \dot q_3\dot q_4\,l_2C\cos(q_4-q_3)\\ &- g\,(A s_2 + B s_3 + C s_4)\end{aligned}$$

External work (corrected):
$W = T_1 q_2 + T_2(q_3 - q_2) + T_3(q_4 - q_3) + F\,(q_1 + l_1c_2 + l_2c_3)$.
This gives $Q_1 = F$, $Q_2 = T_1 - T_2 - Fl_1s_2$, $Q_3 = T_2 - T_3 - Fl_2s_3$
and $Q_4 = T_3$.

## Equations of motion (corrected)

Write $\kappa_{23} = l_1B$, $\kappa_{24} = l_1C$ and $\kappa_{34} = l_2C$.
Every coupling term between angle rows $i$ and $j$ has the form
$\kappa_{ij}[\ddot q_j\cos(q_j-q_i) - \dot q_j^2\sin(q_j-q_i)]$.

(a) $q_1$:
$$F = M\ddot q_1 - A(\ddot q_2 s_2 + \dot q_2^2c_2) - B(\ddot q_3 s_3 + \dot q_3^2c_3) - C(\ddot q_4 s_4 + \dot q_4^2c_4)$$

(b) $q_2$:
$$T_1 - T_2 - Fl_1s_2 = -A\ddot q_1s_2 + J_1\ddot q_2 + \kappa_{23}[\ddot q_3\cos(q_3-q_2) - \dot q_3^2\sin(q_3-q_2)] + \kappa_{24}[\ddot q_4\cos(q_4-q_2) - \dot q_4^2\sin(q_4-q_2)] + gAc_2$$

(c) $q_3$:
$$T_2 - T_3 - Fl_2s_3 = -B\ddot q_1s_3 + \kappa_{23}[\ddot q_2\cos(q_3-q_2) + \dot q_2^2\sin(q_3-q_2)] + J_2\ddot q_3 + \kappa_{34}[\ddot q_4\cos(q_4-q_3) - \dot q_4^2\sin(q_4-q_3)] + gBc_3$$

(d) $q_4$:
$$T_3 = -C\ddot q_1s_4 + \kappa_{24}[\ddot q_2\cos(q_4-q_2) + \dot q_2^2\sin(q_4-q_2)] + \kappa_{34}[\ddot q_3\cos(q_4-q_3) + \dot q_3^2\sin(q_4-q_3)] + J_3\ddot q_4 + gCc_4$$

In matrix form this is $\mathbf M(q)\ddot q + \mathbf h(q,\dot q) + \mathbf G(q) = \mathbf Q$.
$\mathbf M$ is symmetric, with diagonal $(M, J_1, J_2, J_3)$, entries
$-As_2, -Bs_3, -Cs_4$ in row/column 1, and
$\kappa_{ij}\cos(q_j-q_i)$ among the angles.

**Two modelling caveats the book skips.** First, as written, the only
horizontal force on the chain is $F$. The ankle behaves like a
frictionless slider with no ground shear. Second, to *prescribe* the
ankle perturbation $\ddot x$, treat $\ddot q_1$ as known and add an unknown
ground shear $H$ to $Q_1$. Eq. (a) then gives $H$, and (b)–(d) are the
dynamics. For a fixed ankle ($\ddot q_1 = \dot q_1 = 0$), (b)–(d) alone
describe a triple pendulum pinned at the ankle.

## Printed typos

| Where | Printed | Correct |
|---|---|---|
| velo(4), $x$ | $-r_1\dot q_3\sin q_3$ | $-r_2\dot q_3\sin q_3$ |
| $L$ (expanded), $m_2$ PE | $m_2g[I_1\sin q_2 + \dots]$ | $m_2g[l_1\sin q_2 + \dots]$ |
| $L$ (collected) | $-\dot q_1\dot q_4(m_3r_3)$ | $-\dot q_1\dot q_4\sin q_4\,(m_3r_3)$ |
| $W$ | $T_2(q_4 - q_3)$ | $T_2(q_3 - q_2)$ |
| (a) | $(m_1r_1 + m_2l_2 + m_3l_1)$; last term $-\ddot q_4m_3r_3$ | $A = m_1r_1+m_2l_1+m_3l_1$; $-C(\ddot q_4s_4 + \dot q_4^2c_4)$ |
| (b) | $+\dot q_3^2\sin(q_3-q_2)$, $+\dot q_4^2\sin(q_4-q_2)$ | both with $-$ |
| (c) | $-(\ddot q_2)^2\sin(q_3-q_2)$ | $+\dot q_2^2\sin(q_3-q_2)$ |
| (d) | — | correct as printed |

## The coupling lesson

- The four equations are the *minimum* set, and they are tightly coupled.
  Breaking the model at the joints (quasi-DOF + constraints, §8.5) gives
  more equations that are each shorter and carry more information.
- $m_3$ (HAT) appears in $A, B, C, J_1, J_2$, so in all four equations. A
  mass error anywhere corrupts every coordinate, and the errors grow with
  time. Before a model can answer a research question, its anthropometrics
  and joint constraints must be "almost perfect", enough to pass internal
  validation (§8.0.2).

## Relevance to migera

- **An analytic oracle for the ragdoll's physics layer.** With the ankle
  pinned, (b)–(d) describe a 3-body planar chain. An avian chain of three
  capsule bodies, 2 spherical joints and a fixed root could be checked
  against an RK4 integration of these equations. One check is free swing
  with $T = 0$ (compare trajectories over a short horizon and the energy
  drift). Another is a constant torque. This separates avian and
  frame-setup errors from PD-controller errors, which the pose-tracking
  tests cannot do. Use the corrected equations. The printed ones would
  make a correct simulation fail.
- **Coupling explains cross-joint symptoms.** A wrong torque or mass at one
  body shows up as error at *other* joints. This was observed in migera,
  where saturated forearms made the head and feet flail (`CEILING_SCALE`
  notes in `src/character/anim/ragdoll.rs`). Measure each link before
  blaming the joint where the symptom appears
  ([symptom is far from cause in the rig chain](../../engineering-practice/debugging/symptom-is-far-from-cause-in-the-rig-chain.md)).
- **Balance.** This is the multi-link generalisation of the single
  inverted pendulum used for COM/COP balance in chs. 5 and 11. It becomes
  relevant if migera ever gets a physics-based balance controller for an
  unpinned ragdoll.
