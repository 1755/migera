# 8.0.2 Potential of forward solution simulations

> **Source:** Winter (2009) §8.0.2, pp. 201–202 ·
> [open PDF at p. 201](../../../../books/bmcoh/BIOMECHANICS_AND_MOTOR_CONTROL_OF_HUMAN.pdf#page=214) ·
> Up: [8.0 Introduction](./INDEX.md)

Forward simulations could answer "what would happen if...?" questions, but
only once the model has passed an **internal-validity** round trip. Compute
the joint moments by inverse dynamics, feed them into the forward model with
the measured initial conditions, and check that the measured motion comes
back out. A model that fails this test produces only "an erroneous set of
motor patterns overlaid on an erroneous biomechanical model."

## Key ideas

- **Uses.** A surgeon asks what a tendon transfer or a tendon release would
  do. A coach asks whether a runner's pattern is optimal. A researcher tests
  a theory of gait control. Winter says this potential is "tremendous" but
  unrealised, because the requirements of
  [8.0.1](./8.0.1-forward-model-assumptions-and-constraints.md) are so
  severe.
- **Internal validity** is *necessary but not sufficient*. The inverse
  solution must supply moments in every required plane (sagittal, coronal,
  and so on), not only one.
- Passing the test shows only that the model is consistent with itself on
  one movement. It does not show that the model predicts new movements
  correctly.

## Where to read in the book
- pp. 201–202 (PDF 214–215): the uses and the internal-validity argument.

## Relevance to migera

The internal-validity test maps onto a round-trip test for migera's physics:

1. Run the kinematic animation.
2. Compute the torques needed for it, for example by recording the PD
   controller's applied accelerations at strength 1, or by inverse dynamics
   on the rig.
3. Replay those torques open-loop into the ragdoll from the same initial
   pose and velocities.
4. Measure body-vs-target error over time.

§8.1 predicts the result: the error grows and the character falls within
about half a second. This makes the test a way to *measure the drift
horizon*, not a pass/fail gate. It also shows why feedback is required: the
PD error term is what keeps the ragdoll on track. When comparing, apply the
lesson from
[full-strength read-back hides the physics](../../../character-animation/ragdoll-and-physics/full-strength-readback-hides-the-physics.md):
measure the simulated bodies, not the blended output.
