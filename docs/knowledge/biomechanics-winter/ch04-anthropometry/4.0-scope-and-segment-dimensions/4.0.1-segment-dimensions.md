# 4.0.1 Segment dimensions

> **Source:** Winter (2009) §4.0.1, pp. 82–83 ·
> [open PDF at p. 82](../../../../books/bmcoh/BIOMECHANICS_AND_MOTOR_CONTROL_OF_HUMAN.pdf#page=95) ·
> Up: [4.0 Scope of anthropometry in movement biomechanics](./INDEX.md)

The most basic anthropometric quantity is the length of each segment between
joint centers. Absent a direct measurement of the individual, Fig. 4.1 gives
every joint height and segment length as a fraction of standing height *H*
(Drillis & Contini 1966) — a "good approximation in the absence of better
data".

## Key ideas

- Segment lengths vary with build, sex and ethnicity; Dempster (1955, 1959)
  located joint centers relative to palpable landmarks, Drillis & Contini
  averaged the proportions into one figure scaled by *H*.
- The figure is a **stick model in the frontal plane**, standing erect, arms
  abducted horizontally. Heights are measured from the floor; the arm
  lengths are measured along the horizontal arm.
- Prefer measured lengths; use these only as defaults (Winter itself does so
  in later examples when a marker is missing).

## Equations and numbers

Fig. 4.1 read from the rendered page (PDF p. 96, 250 dpi). "Height" = vertical
distance of the landmark above the floor.

| Landmark / dimension | Fraction of H | Notes |
|---|---|---|
| Top of head (stature) | 1.000 | |
| Eye level | 0.936 | dashed line through the eyes |
| Chin | 0.870 | head height top→chin = **0.130 H** |
| Shoulder (glenohumeral) height | 0.818 | |
| Chest line (width 0.174 H) | 0.720 | height of the 0.174 H chest bar |
| Elbow height (arm hanging) | 0.630 | |
| Hip joint (greater trochanter) height | 0.530 | top of the pelvis bar |
| Wrist height (arm hanging) | 0.485 | the figure runs this dashed line across the bottom of the pelvis too, and marks it 0.520 H below the top of the head |
| Fingertip height (arm hanging) | 0.377 | |
| Knee height | 0.285 | |
| Ankle height | 0.039 | |
| Shoulder width (joint to joint) | 0.259 | 0.129 H midline→shoulder joint |
| Chest width | 0.174 | |
| Hip width (joint to joint) | 0.191 | |
| Upper arm (shoulder→elbow) | 0.186 | |
| Forearm (elbow→wrist) | 0.146 | |
| Hand (wrist→fingertip) | 0.108 | |
| Foot length | 0.152 | |
| Foot breadth | 0.055 | |

Derived segment lengths (differences of the heights above, not printed in
the book):

- Thigh (hip→knee) = 0.530 − 0.285 = **0.245 H**
- Shank (knee→ankle) = 0.285 − 0.039 = **0.246 H**
- Whole leg (hip→floor) = **0.530 H**
- Trunk (hip joint→shoulder joint, vertical) = 0.818 − 0.530 = **0.288 H**
- Shoulder→chin (neck) = 0.870 − 0.818 = **0.052 H**
- Hanging arm check: 0.818 − 0.630 = 0.188 ≈ 0.186 (upper arm);
  0.630 − 0.485 = 0.145 ≈ 0.146 (forearm); 0.485 − 0.377 = 0.108 (hand).

For a 1.80 m person: thigh 0.44 m, shank 0.44 m, upper arm 0.335 m,
forearm 0.263 m, foot 0.274 m, hip height 0.954 m.

## Relevance to migera

Direct: a default proportion set for any procedurally generated or scaled
rig, and a sanity oracle for `puppet_base.gltf` (e.g. thigh ≈ shank ≈ 0.245 H,
hip joint at 0.53 H). The thigh and shank being equal is a useful check
against the synthetic rig, whose leg segments are shifted a joint (see
[synthetic-rig leg segments](../../../character-animation/rig-and-retargeting/synthetic-rig-leg-segments-are-shifted-a-joint.md)).
Hip height 0.53 H is also the natural pendulum length for gait timing and a
stride-length prior. Capsule lengths in `src/character/anim/ragdoll_plugin.rs`
come from the rig's own joints, so these fractions are a cross-check there,
not an input.
