# 2.3.2 Normalization of time bases to 100%

> **Source:** Winter (2009) §2.3.2, pp. 42–43 ·
> [open PDF at p. 42](../../../../books/bmcoh/BIOMECHANICS_AND_MOTOR_CONTROL_OF_HUMAN.pdf#page=55) ·
> Up: [2.3 Ensemble averaging of repetitive waveforms](./INDEX.md)

To average or compare strides of different durations, resample each one
onto a common axis of N points spanning 0–100% of the stride, using linear
interpolation between the two nearest original samples.

## Key ideas

- One subject's stride has n samples of x; the normalized curve y has N
  samples, so each normalized step spans n/N original samples.
- Output sample k takes the value at fractional original index $k\,n/N$,
  linearly interpolated.

## Equations and numbers

$$
s_k = k\,\frac{n}{N},\quad j = \lfloor s_k \rfloor,\quad f = s_k - j,\qquad
y_k = (1-f)\,x_j + f\,x_{j+1}
$$

Book example, n = 107, N = 100 (1-based indices):

| k | fractional index | y_k |
|---|---|---|
| 1 | 1.07 | 0.93 x₁ + 0.07 x₂ |
| 2 | 2.14 | 0.86 x₂ + 0.14 x₃ |
| 3 | 3.21 | 0.79 x₃ + 0.21 x₄ |
| 99 | 105.93 | 0.07 x₁₀₅ + 0.93 x₁₀₆ |
| 100 | 107 | x₁₀₇ |

(The printed y₂ drops the subscript on x₃.)

**Implementation note.** The book's mapping sends k = 0 to original index 0,
which does not exist in its 1-based numbering, and its y₁ is not the first
sample. For a closed cycle in code, use 0-based samples covering heel strike
to the *next* heel strike and map $s_k = k\,(n-1)/(N-1)$ (both endpoints
land on real samples), or — for an exactly periodic procedural cycle —
sample the phase function directly at $\varphi_k = k/N$ of the cycle,
$k = 0\ldots N-1$, which needs no interpolation at all.

## Where to read in the book

- pp. 42–43 (PDF 55–56): the full procedure (half a page).

## Relevance to migera

The prerequisite for every quantitative comparison in this chapter. Real
gait data (Appendix A: one stride sampled at the camera rate) and a
procedural walk (a phase function in `gait.rs`/`phase.rs`) live on
different time bases; converting both to % stride — defined from the same
event, e.g. right heel contact — is what makes a point-by-point RMS error,
a correlation, or a harmonic fit meaningful. Be exact about the start
event: a few percent of misalignment shows up as a spurious phase lag in
any later cross-correlation.
