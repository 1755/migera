# 7.1.3 Other possible rotation sequences

> **Source:** Winter (2009) §7.1.3, p. 179 ·
> [open PDF at p. 179](../../../../books/bmcoh/BIOMECHANICS_AND_MOTOR_CONTROL_OF_HUMAN.pdf#page=192) ·
> Up: [7.1 Axes systems](./INDEX.md)

There are 12 valid sequences of three rotations about moving axes, all due to
Euler. Biomechanics commonly uses the Cardan x–y′–z″; mechanical engineering
the "Euler" z–x′–z″. The book lists them but does not compare them — the
point to take away is that the three numbers depend on the sequence.

## Key ideas

- A sequence is valid if no two *consecutive* rotations share an axis. Six
  use three distinct axes (Cardan/Tait–Bryan), six repeat the first axis
  (proper Euler).
- The book's table (primes mark moving axes):

  | | | | |
  |---|---|---|---|
  | x–y′–x″ | **x–y′–z″ (Cardan)** | x–z′–x″ | x–z′–y″ |
  | y–x′–y″ | y–x′–z″ | y–z′–x″ | y–z′–y″ |
  | z–x′–y″ | **z–x′–z″ (Euler)** | z–y′–x″ | z–y′–z″ |

- The book never says which angle is "flexion" etc.; reading it off its own
  examples ([7.2.1](../7.2-marker-and-anatomical-axes/7.2.1-kinematic-data-set-example.md),
  [7.4.3](../7.4-kinetic-analysis-reactions-and-moments/7.4.3-kinetic-data-set-example.md)):
  θ₁ about X (anterior–posterior) is the **frontal-plane** (ab/adduction)
  angle, θ₂ about the long axis y′ is **axial rotation**, θ₃ about z″
  (mediolateral) is **sagittal flexion/extension** — the largest in walking.
  Note that flexion comes *last* here, unlike the joint coordinate system
  (Grood–Suntay) convention common in clinical gait, which puts flexion first.

## Equations and numbers

Same orientation, different sequences (scipy, the book's frame-6 leg
orientation, intrinsic sequences, degrees):

| Sequence | angles |
|---|---|
| XYZ (book) | −8.92, −2.71, −53.27 |
| ZYX | −52.81, −8.75, −3.21 |
| ZXY | −53.30, −3.17, −8.77 |
| YZX | −14.29, −51.94, −14.55 |
| ZXZ (proper Euler) | −163.02, 9.32, 109.97 |

With a small out-of-plane component the Cardan sequences agree to a fraction
of a degree on *which* angle is big, but the small angles shift by ~0.5–6°,
and a proper-Euler sequence gives unrecognisable numbers. Conversely, the
*same three numbers* applied in two orders differ a lot: (30°, 30°, 30°) as
XYZ vs ZYX gives orientations 26° apart.

## Where to read in the book

- p. 179 (PDF 192): the 12-sequence table and the Cardan/Euler naming.

## Relevance to migera

- Any published joint-angle curve is only usable with its sequence and axis
  map. A gait paper's "hip abduction" is not comparable with a migera
  decomposition until both use the same sequence in the same frame.
- Pick the sequence so the **singular middle angle is the one that stays
  small** for that joint: for a hinge-like knee put flexion first or last,
  never in the middle; the heading/axial axis in the middle is fine for a
  joint's *relative* rotation but not for a segment relative to a turning
  world ([7.1.2](./7.1.2-local-reference-systems-and-rotation.md)).
- For swing/twist-style limits (avian's spherical joint,
  [avian joint limits are not cone+twist](../../../character-animation/ragdoll-and-physics/avian-joint-limits-are-not-cone-and-twist.md)),
  a swing–twist decomposition about the bone axis is the quaternion-native
  alternative to any of these 12 sequences.
- Test decompositions against `Rotation.as_euler(seq)` in scipy; never
  against a hand-expanded matrix from the same derivation.
