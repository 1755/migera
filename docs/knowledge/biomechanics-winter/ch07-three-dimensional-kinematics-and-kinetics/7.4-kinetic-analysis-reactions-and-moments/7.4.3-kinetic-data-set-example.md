# 7.4.3 Example of a kinetic data set

> **Source:** Winter (2009) §7.4.3, pp. 191–194 ·
> [open PDF at p. 191](../../../../books/bmcoh/BIOMECHANICS_AND_MOTOR_CONTROL_OF_HUMAN.pdf#page=204) ·
> Up: [7.4 Kinetic analysis of reaction forces and moments](./INDEX.md)

One frame of left-shank stance data run through all steps: Newton in global,
rotate into anatomical axes, angular kinematics, Euler's equations → the
three knee moments, then an anatomical reading of them. I recomputed it in
numpy; all results match to the book's rounding.

## Equations and numbers

Shank: m = 3.22 kg, I_x = 0.0138, I_y = 0.0024, I_z = 0.0138 kg·m²,
l_d = 13.86 cm, l_p = 18.15 cm, 60 Hz. Frame-6 COM acceleration
a = (7.029, 1.45, −0.348) m/s², g = 9.814.

**Step 1 (global):** R_P = (−96.41, −755.17, −13.15) N.

**Step 2–3 (rotate):**

$$[G\to A]_6=\begin{bmatrix}0.8955&-0.4363&0.0875\\0.4443&0.8877&-0.121\\-0.025&0.1473&0.9888\end{bmatrix}$$

R_d = (237.65, −754.00, −125.50) N; R_p = (241.99, −711.61, −121.83) N;
M_d = (2.79, 20.79, −102.73) N·m (anatomical).

**Kinematics:** ω₅ = (−0.1646, −0.0249, −2.637), ω₆ = (−0.0350, −0.1344,
−2.907), ω₇ = (−0.0542, −0.1362, −3.206) rad/s; central difference
α₆ = (ω₇ − ω₅)/(2Δt) = (3.312, −3.337, −17.07) rad/s².

**Euler (7.9) solved for the proximal (knee) moments, frame 6:**

| Moment | Value | Dominant terms |
|---|---|---|
| M_xp | **+42.35 N·m** | 121.83·0.1815 + 125.5·0.1386 + M_xd 2.79 (inertial 0.05) |
| M_yp | **+20.78 N·m** | ≈ M_yd; I_yα_y = −0.008 |
| M_zp | **−26.11 N·m** | −102.73 + 241.99·0.1815 + 237.65·0.1386 (inertial −0.24) |

Exercise answers: frame 5 (a = 5.89, 1.30, −1.66) → (40.76, 21.61, −31.23)
N·m; frame 7 (a = 9.60, 1.94, −0.020) → (41.85, 19.20, −19.80) N·m.

**Interpretation (left knee, single support).** +M_x = **abductor** moment
resisting the body weight acting medial to the stance limb; M_y = axial
moment from the hip internal rotators swinging the pelvis/other limb forward;
−M_z = **flexor** moment helping start knee flexion before toe-off. The knee
moments are then rotated back to global ([A to G]) as the distal moments for
the thigh — the chain proceeds upward exactly as in 2D.

**Book inconsistencies (checked):**
- The worked M_zp line prints "−R_zp l_p"; the arithmetic (and Eq. 7.9c) use
  R_xp.
- Inertial terms are negligible: all Iα and ωω terms together are < 1 % of
  each moment (0.1 % for M_x, 0.9 % for M_z). In stance the knee moment is essentially statics of the
  reaction forces.
- l_d = 13.86 and l_p = 18.15 cm are swapped relative to the §7.2.1 shank
  (there the ankle is 18.15 cm and the knee 13.86 cm from the COM). The book's
  arithmetic uses its stated values; with the §7.2.1 geometry M_xp would be
  42.47 and M_zp −26.30 N·m.

## Relevance to migera

- **Fixture for a dynamics test.** Tables 7.3/7.4 in, three moments out — a
  known-answer test for any per-segment 3D dynamics helper, or to validate a
  Rust port of Eq. 7.7b + 7.9 against numbers not produced by the same code
  ([same function both sides is a vacuous test](../../../engineering-practice/testing/same-function-both-sides-is-a-vacuous-test.md)).
- **Magnitudes.** ~42 N·m knee abductor and ~26 N·m flexor with ~790 N of vertical
  ankle reaction (an ~80 kg subject) in stance are a plausibility bound for ragdoll leg joint torques
  when a strength-blended ragdoll must hold the body up.
- **Stance is quasi-static.** Inertial terms < 1 %: a standing/walking
  ragdoll's support torques are governed by gravity and contact geometry,
  so its joint torque demand can be estimated from a static pose.
